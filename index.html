Rekam Audio & Video (single HTML)

Fitur: pilih kamera depan/belakang, mode audio-only, pengaturan gain yang mempengaruhi waveform, dan unduh rekaman.

Nilai: 1.00
Browser akan menentukan MIME (WebM/ogg). Untuk distribusi APK, WebM umumnya didukung.

Catatan & Packaging

Di dalam file ini ada semua kode yang diperlukan. Untuk membuat APK, salin file ini ke folder www pada Cordova/Capacitor, tambahkan permission Android (RECORD_AUDIO, CAMERA), lalu build. Instruksi singkat di bawah (lihat komentar di source code untuk langkah lebih lengkap):

  • Cordova: cordova create app → ganti www → cordova platform add android → cordova build android
  • Capacitor: buat proyek web, copy file ke build, npx cap add android, npx cap open android lalu build di Android Studio.
